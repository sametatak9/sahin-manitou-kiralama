# Reels müzik havuzu

Bu klasöre koyulan her `.mp3` / `.m4a` parçası otomatik Reels montajında sırayla kullanılır (her videoda farklı parça).
Yalnızca ticari kullanımı serbest (telifsiz) parçalar ekleyin — ör. Pixabay Music, YouTube Ses Kitaplığı ("atıf gerekmez" olanlar).
Klasör boşsa varsayılan `scripts/reels/music.m4a` kullanılır.
